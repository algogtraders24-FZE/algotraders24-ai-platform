## Property/invariant checklist (Q0.3.19, exact numbering)

1. A trailing stop cannot move backward — `risk-invariants.test.ts` (sampled price path) + `risk-trailing.test.ts` (direct cases).
2. A valid BUY stop cannot be above entry — `risk-invariants.test.ts` + `risk-geometry.test.ts`.
3. A valid SELL stop cannot be below entry — same.
4. A rejected entry cannot produce ALLOW_ENTRY — `risk-invariants.test.ts`.
5. Daily loss above limit cannot produce ALLOW_ENTRY — `risk-invariants.test.ts`.
6. Maximum position count cannot be exceeded — `risk-invariants.test.ts` (swept range) + `risk-position-limits.test.ts`.
7. Partial close quantity cannot exceed current position — `risk-invariants.test.ts` (swept percents) + spec-level guarantee from Q0.2's `validateRiskSpecification`.
8. Risk evaluation cannot mutate input objects — `risk-invariants.test.ts` + full deep-freeze proof in `risk-immutability.test.ts`.
9. Future timestamps cannot affect historical evaluation — `risk-invariants.test.ts`.

## What is explicitly NOT tested (because it does not exist, by design)

No test exercises a candle-loop backtester, an order-matching engine, an optimizer, walk-forward/CPCV/PBO/DSR/Monte Carlo, or any M-Series/`market.db`/old-Quant-engine code path — none of that exists in `at24-quant-engine/`, in Q0.3 or any prior sprint.
