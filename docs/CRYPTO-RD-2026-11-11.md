# Crypto / Bitcoin R&D - what AT24 can build (2026-11-11)

## What we already know (do not repeat)
- Arena / Binance paper desk (2026-10): 9 price-rule strategies on 30 coins, pre-registered, **none passed**; the rules arm has no edge over random entries. The Claude desk is a forward test (weeks), no results to claim.
- Research Lab C1 (this week, `ea-research/indicators/_lab/reports/LAB-C1-CRYPTO-REPORT.md`): BTC funding extremes do not predict the next 24 h reliably, no weekend effect; the delta-neutral funding carry fell from 36 %/yr (2021) to about 3.5 %/yr (2026) before costs.
- Gold labs 01-06: no tradable edge either. So the credible position is "context, honesty and tools", not signals.

## Free data that exists (checked live today, no keys)
Binance futures public REST: funding history back to 2019, open interest history and long/short ratio (**only the last 30 days**), premium-index (basis) klines; Deribit public DVOL (BTC implied-volatility index); Alternative.me Fear & Greed; CoinGecko global; Hyperliquid and Bybit public endpoints. Paid/aggregated: Coinglass (liquidation heatmaps), CoinAPI, Glassnode (on-chain). **Key insight: OI and long/short history cannot be backfilled beyond 30 days, so a collector that stores daily snapshots from today builds a dataset nobody else can download later.**

## Options ranked
1. **Edge Truth Test for crypto traders (web, CSV upload).** Binance/Bybit users cannot run MT5 indicators. A page where a trader uploads the exchange trade-history CSV (futures or spot) and gets the same verified engine: sign-flip p, bootstrap range, drawdown vs shuffled orders, verdict "cannot be told from luck / unlikely luck / too few trades". No API keys (CSV only), computation in the browser. Reuses the verified core (AT24_TT_Core, deterministic xorshift, Python reference exists). Lowest risk, new audience, strongest honesty angle.
2. **AT24 Crypto Pulse (website page + daily social card + optional Telegram).** Percentile ranks versus the last 90 days for funding, open interest, basis, long/short ratio, DVOL and Fear & Greed for BTC/ETH, with the honest note that Lab C1 found no predictive edge (it is a crowding/leverage context gauge, like the News Risk Clock). Data from free public endpoints via a cron; MT4/TV cannot WebRequest so the website is the right home (same logic as the Macro Dashboard plan).
3. **Snapshot collector (start now, tiny).** Daily/4-hourly store of OI, long/short ratio, funding, basis, DVOL for BTC/ETH (and a few majors) so that in 6-12 months Lab C2 can test OI/leverage-flush hypotheses on data nobody else has. Cost: a small cron + one table (watch Supabase egress; store compact rows) or a JSON file on the VPS.
4. **AT24 Crypto Pack for MT5 (BTCUSD/ETHUSD CFDs).** Existing indicators that need no session logic work as they are (History Doctor, Edge Truth Test, Forward Ledger, Cost Clock for the spread, Expected Range, Volatility Forecast, Drawdown/Position tools). Those tied to FX sessions (NY hour, daily break, ServerClock detected from the Friday close) need a "24/7 mode"; the new DetectAny/manual-clock fallback already helps. Brokers differ (some close weekends); needs one BTCUSD demo to test. Small effort, but only reaches MT5 crypto-CFD users.
5. **Public crypto Forward Ledger / transparent scoreboard** (pre-registered BTC rules tallied out of sample, with the random baseline), tied to the Arena. Credibility product, not a profit product; only worthwhile if there is a rule worth registering (none yet).
6. **Not recommended:** funding-carry bot (yield now ~ T-bill level), copy trading (owner shelved), any "AI signal" claims (no edge found, lawyer questions).
