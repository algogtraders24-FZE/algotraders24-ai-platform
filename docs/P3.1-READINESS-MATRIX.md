### The three blockers, as resolved

1. **Package boundary — RESOLVED.** `at24-quant-engine` now has `package.json` `main`/`exports`/`types` pointing at its existing `dist/` build; `frontend` consumes it via a real `file:` dependency, verified with a working `import { runSimulation, buildGoldenStrategySpec } from "at24-quant-engine"`. See `P3.2A-INTEGRATION-FOUNDATION.md`.
2. **Historical-bars source — RESOLVED**, with one disclosed limitation. A `HistoricalDataProvider` abstraction now exists, backed by an isolated adapter over real `market.db` XAUUSD M5 data (116,387 bars, 2024-01-01→2026-05-31), fully validated. **Known limitation, not yet solved**: this data source only works where the local `market.db` file is reachable (gitignored — absent from every git worktree, CI, and any deployed environment) — a real P3.2B/production-deployment prerequisite, not silently glossed over. See `P3.2A-HISTORICAL-DATA-CONTRACT.md`.
3. **Canonical-ownership decision — RESOLVED (signed off for this phase).** `P3.2A-QUANT-LITE-BOUNDARY.md` records the explicit "two systems, scoped apart" decision, with the one permitted crossing (a data-only isolated adapter) fully documented, and confirms via `git diff --stat` that no Quant Lite code was touched.
4. **Execution-assumption disclosure** — not newly built (no UI in this sprint, per its Hard Scope Boundary), but reconfirmed still true and still available on every trade record (`executionMetadata.spreadModel === "ZeroSpread"` etc., verified on the real Golden Run) — remains a **P3.2B UI requirement**, not yet implemented.

### Golden Strategy — real run, twice, byte-identical
Run against real XAUUSD M5 data via the new provider; `resultHash`, trade sequence, entry/exit prices, P&L, metrics, and the derived equity curve were all byte-identical across two independent runs. Full numbers in `P3.2A-RESULT-CONTRACT.md`.
