## Blocker 1 — Package Export

### What was inspected first
`at24-quant-engine/package.json`: pure ESM (`"type": "module"`), `tsc -p tsconfig.build.json` already builds a real, current `dist/` (confirmed `dist/index.js`/`dist/index.d.ts` existed and were fresh before any change). No Python/other runtime involved — this is a plain TypeScript/Node package, confirmed rather than assumed.

### The additive change
```json
{
  "main": "./dist/index.js",
  "types": "./dist/index.d.ts",
  "exports": {
    ".": {
      "types": "./dist/index.d.ts",
      "import": "./dist/index.js",
      "default": "./dist/index.js"
    }
  },
  "files": ["dist"]
}
```
(`"default"` was added alongside `"import"` after discovering tsx's CJS-style resolver rejects an `exports` map with only an `"import"` condition — a real, verified need, not a speculative one.)

**No internal implementation paths are exposed** — `main`/`types`/`exports` point exclusively at the built `dist/index.js`/`dist/index.d.ts` barrel; a consumer cannot reach `dist/runtime/simulation/...` or any other internal path directly (Node's `exports` map is exclusive once present — anything not listed under `"."` is unreachable from outside the package).

### One targeted addition to what's exported: the Golden Strategy
`buildGoldenStrategySpec()` previously lived only in `test/fixtures/simulation-fixtures.ts` (a test-only file). Per the brief's later "use the existing P3 Golden Strategy, do not create another" instruction, and since a test-fixture file is not part of any public entry point, it was **relocated** (not duplicated) to `src/reference/golden-strategy.ts` and re-exported from `src/index.ts`. The test suite now imports it from the same new location (`test/fixtures/simulation-fixtures.ts` re-exports it for backward compatibility with every existing test file's import path). This is the single, canonical Golden Strategy definition — verified zero behavioral drift by re-running the engine's own golden-fixture tests (`simulation-e2e-golden.test.ts`, `q09-mql-e2e-golden.test.ts` — 15/15 pass, exact same hand-verified numbers as before the move: entry 102, exit 111, grossPnl 9, rMultiple 1.5).

No redundant tests were added — the engine's own 1000+ existing tests (re-run in full, see Regression below) already protect everything inside `at24-quant-engine` itself; this new suite only covers the genuinely new code (the provider, the validator, the composition function).

### A known limitation surfaced by testing, not fixed in this sprint
`quant_engine/market.db` is gitignored and does not exist inside any git worktree — including the isolated one this sprint's own code was built and tested in. Running the real-data tests required pointing the new `AT24_MARKET_DB_PATH` environment variable override at the file's real location on this machine. This is expected in the *shared, non-worktree* working directory (where the file already exists at its default relative path) but is a real, disclosed gap for any future CI/deployment environment — recorded in `P3.2A-HISTORICAL-DATA-CONTRACT.md`'s "known limitation" note, not silently absorbed.
