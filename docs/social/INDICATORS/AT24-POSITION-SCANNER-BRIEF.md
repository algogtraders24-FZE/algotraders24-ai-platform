# AT24 Position Scanner - brief

One table for many symbols, using the exact same rules as AT24 Position Map. Planning tool, not a signal.

- Weekly structure (HH+HL up, LH+LL down) is the only direction; RANGE means no trade.
- Each row: weekly trend, what the rules wait for (pullback depth, H4 turn, running plan), entry, stop, TP 1:3, risk in weekly ATR, record of the same rules on that symbol (shown only as a number with n; under 30 setups no claim).
- Triggered symbols sort first; optional alerts on trigger and on H4 turn; closed bars only, non-repainting.
- Input: symbol list (default 15 FX / metals / oil / indices), broker suffix, rules inputs.
- Platform: MT5. Price: 33 USD (series standard). No profit claims; past results do not predict future results.
- Test status: rows identical to Position Map; alerts, swap/lots not verified live.
