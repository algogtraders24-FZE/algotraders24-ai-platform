# Q1.7 Part 3 — Dependency Audit

`npm audit` was re-run this sprint (read-only; no `npm audit fix`, no `npm audit fix --force`). **14 findings today** (4 moderate, 10 high) — up from the 12 Q1.5 recorded, because the npm advisory database and this repo's own dependency graph both moved in the elapsed time (new advisories published against packages already in the tree, e.g. `hono`/`js-yaml`/`nanoid`/`fast-uri`/`brace-expansion`, none of which are new *dependencies* — they were already present, just not separately flagged at Q1.5 time). This drift is stated plainly rather than silently reconciled to match the brief's "12" figure.

Every dependency chain below was traced with `npm ls <package>` to find its real root cause, not assumed.

## Why nothing was upgraded this sprint

Every single finding traces to one of exactly two roots: **`next`** (real runtime code, but a framework-wide bump is explicitly out of this sprint's Quant-Lite-only scope and would need full-site regression testing far beyond what this sprint can responsibly cover) or **`prisma`/`eslint`/`typescript-eslint`** (dev-only tooling, zero Quant Lite runtime exposure, but bumping any of them ripples into the unrelated production Prisma layer or the whole codebase's lint/type tooling — both explicitly protected/out-of-scope per this sprint's own "DO NOT TOUCH... unrelated frontend work" and "if upgrade affects unrelated production/M-Series architecture: DOCUMENT ONLY" instructions). No dependency in this list is one Quant Lite itself pulls in directly, and no genuinely isolated, zero-blast-radius fix exists for any of them today (verified, not assumed, for the one candidate — `@tailwindcss/postcss` — that looked plausible at a glance).

**Classification summary: 0 KEEP, 0 UPGRADE, 14 DEFER, 0 REMOVE.** All 14 are real, correctly triaged, and none block Quant Lite's own beta readiness (zero direct Quant Lite runtime exposure in any of them) — this is documented honestly as a standing follow-up, not silently dropped.

## Recommended follow-up (not this sprint)

A dedicated, isolated sprint scoped specifically to `next`/`prisma`/`eslint` version currency, run with full whole-app regression (not just Quant Lite's 375 assertions) before landing — exactly the recommendation Q1.5 already made and Q1.6 didn't need to revisit, now reconfirmed unchanged.
