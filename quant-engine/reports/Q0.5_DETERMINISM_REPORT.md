# Q0.5 — Determinism Report

Every engine × spec combination run twice, identical inputs
(`XAUUSD_EXNESS` 2024, `quant_lite_risk_config()`), full pipeline (real
data for all three, including `execution_tick.py`'s full 34,194,748-tick
replay per run — not a shortcut or reduced sample).

## Results

| Engine | Spec | Run 1 == Run 2? | Comparison basis |
|---|---|---|---|
| `runner.py` | MACD Crossover | **True** | Full `stats` dict + full trade-by-trade ledger (JSON) |
| `runner.py` | Bollinger Mean Reversion | **True** | Same |
| `execution_mtf.py` | MACD Crossover | **True** | Same |
| `execution_mtf.py` | Bollinger Mean Reversion | **True** | Same |
| `execution_tick.py` | MACD Crossover | **True** | Same |
| `execution_tick.py` | Bollinger Mean Reversion | **True** | Same |

**6 of 6 pass.** No STOP condition triggered — determinism was never in
question for any of the three engines, consistent with Q0.3's and
Q0.4's own earlier determinism checks (`demo.py` reproduction, the Q0.4
MACD/Bollinger repeat-run tests).

## Comparison method

Equality was checked on both the full `stats` dict (every field,
including `account_blown`, `same_minute_sl_tp_conflicts` /
`same_tick_sl_tp_conflicts` where applicable) **and** the complete
trade-by-trade ledger (every `entry_time`, `exit_time`, `direction`,
`entry_price`, `exit_price`, `volume`, `pnl`, `reason` — serialized to
JSON, compared as Python dict/list equality, not just row counts or
summary stats). A determinism failure that only changed, say, the 47th
trade's exit price by a rounding difference while leaving the summary
stats unchanged would have been caught by this method; none occurred.

## Why this matters given this sprint's other finding

The signal-timing bug documented in
[`Q0.5_CROSS_ENGINE_MATRIX.md`](Q0.5_CROSS_ENGINE_MATRIX.md) is a
**consistent, deterministic** bug — it fires the same way every time
given the same input, which is exactly why it was fully reproducible
both on real data and in a controlled synthetic scenario. Determinism
and correctness are independent properties: an engine can be perfectly
deterministic while still being wrong, and this sprint found a concrete
case of exactly that. Determinism alone does not clear an engine for
canonical status — see
[`Q0.5_CANONICAL_ENGINE_DECISION.md`](Q0.5_CANONICAL_ENGINE_DECISION.md).
