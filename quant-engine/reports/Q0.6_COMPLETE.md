# Q0.6 — Complete

## Executive summary

Fixed the confirmed look-ahead defect in `execution_mtf.py` (Q0.5
finding), verified the fix three independent ways (controlled synthetic
scenario, real-data convergence with the never-buggy `runner.py`,
real-data divergence from the still-buggy, deliberately-untouched
`execution_tick.py`), and re-ran Q0.5's exact cross-engine comparison.
The fix is a single-condition, one-line change plus an expanded comment
— no other behavior touched. Impact was material and bidirectional: MACD
Crossover's apparent performance was substantially *inflated* by the bug
(PF 1.76→1.15); Bollinger Mean Reversion's was substantially *understated*
(PF 0.26→0.99, near-ruin →near-breakeven). `execution_mtf.py` is now
promoted to canonical.

## Exact source change

`quant-engine/spec_engine/execution_mtf.py`, one line's condition:

```python
# before (look-ahead: bar marked closed at its own START timestamp)
while sig_ptr < len(sig_rows) and sig_ts[sig_ptr] <= ts_i:

# after (bar marked closed only at its real END - the NEXT bar's start)
while sig_ptr < len(sig_rows) - 1 and sig_ts[sig_ptr + 1] <= ts_i:
```

Plus an expanded comment explaining the left-labeled-timestamp semantics
and why the fix is data-driven, not a hardcoded timeframe assumption.
`git diff --stat`: 1 file changed, 20 insertions, 8 deletions — all
within the signal-pointer-advancement block; no other line touched.

## Test results

- **Synthetic look-ahead test:** BEFORE (Q0.5) entered at the jump bar's
  first minute using the pre-jump price; AFTER (this sprint) enters only
  at the bar's real close, using the real post-jump price. Fix confirmed.
- **Regression tests E-J:** basic BUY/SELL → TP/SL scenarios run;
  risk-percentage sizing confirmed to scale exactly proportionally (2%
  risk = exactly 2x the 1% risk loss on an identical trade); MTF
  signal/execution split confirmed structurally intact. Two synthetic
  cases (E, G) showed a trade-count difference between `runner.py` and
  `execution_mtf.py` consistent with the already-documented, pre-existing
  granularity difference between the engines — not asserted as fix-caused
  without the real-data evidence, which independently confirms the fix
  is correct via a different, more authoritative method (see below).
- **MACD/Bollinger 2024 real-data rerun:** completed, full results in
  `Q0.6_REVALIDATION_MATRIX.md`.
- **Determinism:** 6/6 pass (both fixed and unmodified engines,
  `Q0.6_DETERMINISM.md`).
