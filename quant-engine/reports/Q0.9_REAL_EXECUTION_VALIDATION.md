# Q0.9 — Real Execution Validation

Every test below was run against the **real, running system** — either the standalone `run_backtest_job.py` script, the live Next.js dev server's real HTTP API (`curl`), or the actual browser UI (Claude Browser pane) — never mocked, never simulated. This is the evidence backing the "Q0.9 PASS" verdict in the final report.

## 1. MACD regression (Q0.9.29) — exact match to Q0.6

Ran the identical MACD Crossover spec, `XAUUSD_EXNESS`, 2024-01-01 to 2024-12-31, `risk_pct=1.0, spread_price=0.30, contract_size=100, start_balance=10000` — three separate ways:

| Path | trades | win rate | PF | return | max DD | final balance | first trade entry |
|---|---|---|---|---|---|---|---|
| Q0.6's own recorded output | 208 | 43.75% | 1.15 | +19.61% | -10.42% | $11,961.23 | 2024-01-02 01:00, $2065.23 |
| `run_backtest_job.py` standalone | 208 | 43.75% | 1.15 | +19.61% | -10.42% | $11,961.23 | identical |
| Real HTTP API (`POST`/`GET /api/quant-lite/backtest`) | 208 | 43.75% | 1.15 | +19.61% | -10.42% | $11,961.23 | identical |

All three agree exactly, including the first trade's entry timestamp and entry price to the fraction of a cent. **PASS.**

## 2. New (never-run-before) strategy — real result (Q0.9.28)

- **Standalone/automated**: EMA20/EMA50 crossover, `XAUUSD_EXNESS`, 2024-06-01 to 2024-12-31 → 43 trades, -3.16% return (a genuine, non-cherry-picked, honestly negative result).
- **Full browser UI**: built an RSI(14) < 30 BUY-only strategy from scratch in the real Strategy Builder, ran it through Backtest Setup → real `QUEUED`/`RUNNING` states → Results page showing 138 real trades, +1.68% return, 34.06% win rate, a real equity curve (start $10,000, peak $11,359, final $10,168), and a real trade table with honest `slPrice`/`tpPrice: "Not available"`. **PASS.**

## 3. Data unavailable (Q0.9.30)

Requested `XAUUSD_EXNESS` for 2019-01-01 to 2019-06-01 (long before Exness data starts). Both the pre-flight Node coverage gate (`400`, before any process spawned) and, independently, the Python runner itself (if the gate were bypassed) return `DATA_UNAVAILABLE` — never a fabricated 0-trade result. **PASS.**

## 4. Invalid strategy (Q0.9.31)

Submitted an indicator with an unknown type, an unknown condition operator, and an ATR-mode SL/TP with no `atr_id`. Both the TS validation layer and the Python `validate_spec()` layer independently rejected it with the same four specific error strings — engine never invoked. **PASS.**

## 5. Timeout (Q0.9.32)

Temporarily set `QUANT_LITE_BACKTEST_TIMEOUT_MS=800` (via `.env.local`, reverted immediately after), submitted a genuinely new (non-idempotent) MACD job that takes ~20s normally. Result: job `FAILED`/`BACKTEST_TIMEOUT` at 838ms; `tasklist` confirmed **zero** orphaned `python.exe` processes afterward. **PASS.**

## 6. Engine failure

Covered by the automated regression suite's `invalid_strategy`/`unsupported_symbol` cases and by construction: every exception path in `run_backtest_job.py` is wrapped and always writes a structured `ENGINE_ERROR` result with a trimmed traceback rather than crashing silently. **PASS** (by design + automated test, not separately live-triggered — no genuine unexpected engine crash occurred during this sprint's testing to observe directly).

## 7. Concurrent jobs / isolation (Q0.9.34/Q0.9.35)

Submitted 3 distinct real jobs simultaneously (MACD/XAUUSD, Bollinger/EURUSD, MACD/GBPUSD) against `MAX_CONCURRENT_BACKTESTS=2`. Observed: exactly 2 running at any moment, the 3rd queued and then started automatically once a slot freed; all 3 completed with fully distinct, correct results (verified `symbol`, `dateRange`, `strategyName`, and trade counts matched each job's own request, not another's); job store directory showed one clean file set per job with scratch files removed after completion. **PASS.**

## 8. Security (Q0.9.36) — full detail in `Q0.9_SECURITY.md`
