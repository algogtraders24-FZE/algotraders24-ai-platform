## Summary

Every feature Quant Lite's frozen contract actually declares supported has `EXACT` semantic parity across all four surfaces (Python backtest, MQL4, MQL5, Pine) — the only two `PLATFORM-DIFFERENCE` rows are inherent to comparing a simulated backtest against real broker mechanics (same-bar tie-break; position-sizing unit conversion), not defects, and both are already documented in the generators' own code comments, not newly invented for this report. Every `UNSUPPORTED` row is a feature the schema itself cannot express — no generator silently approximates any of them.
