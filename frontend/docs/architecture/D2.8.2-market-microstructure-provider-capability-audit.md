# D2.8.2 — Market Microstructure Provider Capability Audit

**Status:** Audit/research complete. No production code changed. **Baseline:** D2.8.1 (`b788c6d`).
**Scope:** Evidence-based audit of which external providers (dxFeed, Databento, Angel One SmartAPI, Twelve Data, Alpha Vantage) could supply the market-microstructure capabilities (tick, Time & Sales, L2/L3, aggressor side, historical order-book) this platform currently does not have — and which AT24 instruments each provider actually covers. **No provider was integrated. No production architecture was modified.**

---

## 1. Executive finding

AT24's current, real capability (post-D2.8.1) is: OHLC + volume where a provider reports it, plus one real bid/ask/spread pair (EURUSD via Alpha Vantage). Everything below that — tick data, Time & Sales, any order-book depth, aggressor-side classification, historical tick/book data, execution data — is **currently unavailable from any wired provider**, and nothing in the codebase fabricates a substitute (confirmed fresh in §13).

Of the five researched candidates, **none can serve AT24's full instrument set with real microstructure data through a single account**:

- **dxFeed** and **Databento** are institutional, exchange-native data vendors. Both can supply genuine L2/L3, aggressor-side, and historical tick/book data — but **only for exchange-listed instruments** (COMEX futures, CME/ICE FX futures, listed equities/crypto exchanges). Neither vendor's coverage is a drop-in match for AT24's actual instruments: **AT24's XAUUSD/EURUSD are retail spot/CFD-style prices, not the COMEX gold future or the CME FX future** dxFeed/Databento would actually deliver order-book data for, and **Databento does not currently support cryptocurrencies and has no confirmed Indian-exchange (NSE) coverage at all**.
- **Angel One SmartAPI** — AT24's own existing, already-integrated Indian provider — genuinely does document a 5-level (`Full` mode) and 20-level (`WebSocket 2.0 Depth 20`) market-depth capability for NSE instruments including NIFTY/BANKNIFTY, but **AT24's current adapter uses neither** (only the REST `getLtpData`/`getCandleData` endpoints — no WebSocket, no depth). This is the one candidate where "add capability" and "already integrated" are the same provider — see §10.
- **Twelve Data** and **Alpha Vantage** — AT24's existing FX/metals/crypto providers — are both confirmed, by their own documentation, to offer no tick, Time & Sales, L2, or L3 data at any tier; both are quote/OHLC vendors, full stop.

**No single provider satisfies Tier-1 requirements across NIFTY/BANKNIFTY + EURUSD/GBPUSD + XAUUSD/XAGUSD + BTCUSD/ETHUSD.** A genuine future integration would need to be multi-provider and per-asset-class, and even then would face the recurring "which exact venue/instrument" distinction called out in §3.

## 6. dxFeed detailed findings

- **Quote/Trade/Time & Sales:** confirmed as core dxFeed market events (kb.dxfeed.com's Market Events documentation family), consistent with dxFeed's general real-time feed architecture.
- **Order Book / Price Level Book / Full Order Depth:** confirmed. Full Order Depth (FOD) delivers per-order data but *without* Order IDs or action types — the consumer must reconstruct the book from `Index`/`EventFlags` fields.
- **Enhanced Order Book (EOB):** confirmed as a *distinct, richer* product on top of FOD — adds Order IDs, action types, trade prices, and explicitly **"aggressor order information."** This is the specific product that would satisfy AT24's Tier-1 "trade/aggressor classification" requirement, where it applies.
- **Historical availability:** confirmed — dxFeed's historical-data-services page describes tick-level and aggregated historical feeds, with a stated capacity of storing "up to 10TB of raw data per day" (per the earlier search summary), available via API or file download.
- **Supported exchanges/asset classes relevant to AT24:** confirmed COMEX (precious/base/ferrous metals futures, including gold), CME/ICE (FX futures, equity index futures), and "normalized market data for all main cryptocurrencies from the top 20 crypto exchanges." **Not confirmed**: whether dxFeed's crypto normalization includes Binance specifically (AT24's actual crypto source), or whether its "consolidated FX" product is priced/timed comparably to AT24's current retail-spot FX quotes.
- **Instrument-vs-venue warning (per the sprint's explicit instruction):** dxFeed's gold coverage is the **COMEX GC futures contract**, not a retail XAUUSD spot/CFD quote. Presenting dxFeed order-book data as "AT24's XAUUSD order book" would misrepresent the instrument. Same caveat applies to dxFeed's FX futures/consolidated-FX products versus AT24's current retail EURUSD/GBPUSD quotes.
- **Trial/testing:** confirmed sales-gated trial (5 business days), plus a public unauthenticated demo WebSocket/reference-data endpoint that does not itself constitute usable real-time market data access.
- **Commercial licensing:** confirmed to require explicit approval for any redistribution ("you must obtain all required approvals for control and redistribution of such third-party services, and upon request provide a copy to dxFeed" — dxfeed.com/3pty/, via search); exact commercial pricing was **not verified** from an authoritative first-party page this sprint (only third-party reseller estimates were found, which are not treated as confirmed here).

## 7. Databento detailed findings

- **Datasets/schemas:** confirmed MBO (market-by-order, full L3 — "per-order events for queue position modeling and exact book reconstruction") and MBP-10 (market-by-price, L2 — "top 10 levels with trades... includes orders per level") as real, documented schemas (databento.com/docs/schemas-and-data-formats/{mbo,mbp-10}).
- **Exchange coverage relevant to AT24:** confirmed CME, CBOT, NYMEX, COMEX (all futures/options), plus ICE, EEX, Eurex; confirmed 50+ trading venues as a licensed distributor/direct provider (databento.com/venues, via search summary).
- **Forex:** **not currently offered** — Databento's own materials describe forex as something they are "considering... based on user demand," not a shipped dataset.
- **Cryptocurrency:** **confirmed not supported** — "Databento does not currently support cryptocurrencies or digital assets" (search-summarized from official coverage pages). This directly rules Databento out for AT24's BTCUSD/ETHUSD requirement.
- **Indian markets (NSE):** **no confirmed coverage found**. Nothing in Databento's public venue/coverage materials located this sprint mentions NSE or any Indian exchange; absence of evidence is treated here as **NOT VERIFIED / likely unavailable**, not as a confirmed "yes."
- **Historical data:** confirmed extensive historical tick/MBO/MBP availability (their core product — "Historical Tick Data - Intraday historical data APIs").
- **Live streaming:** confirmed as a real-time capability across their listed schemas (their front-page and per-asset-class pages advertise "real-time & historical" throughout).
- **Cost model:** confirmed usage-based pricing (pay for what you query) plus an unlimited flat-rate tier option; **$125 free credit confirmed**, applicable to historical data or a first subscription month.
- **Commercial licensing:** confirmed self-serve, published, with Databento explicitly positioned as "a licensed distributor and direct provider of market data" — the most self-serve-friendly licensing posture of the five candidates researched.
- **Instrument-vs-venue relevance:** for the one AT24 asset class Databento *does* cover well (metals via COMEX futures), the same futures-vs-spot distinction from §3/§6 applies — Databento's gold/silver data is the COMEX contract, not AT24's XAUUSD spot/CFD quote.

## 8. Angel One SmartAPI detailed findings

- **NIFTY / BANKNIFTY / NSE:** confirmed — this is AT24's own already-integrated provider; `lib/market-data/instrument-catalog.ts`'s live-verified mappings (D2.6.6) already cover NIFTY 50 and NIFTY Bank via real, fetched instrument tokens.
- **Market depth:** confirmed available from Angel One itself, **but not used by AT24's adapter today**. Two documented tiers: `Full` market-data mode returns depth for "best five buy and sell orders" (a form of L2); a newer `WebSocket 2.0` "Depth 20" mode (currently described in Angel One's own forum documentation as beta/rolling out) returns 20-level depth. AT24's `AngelOneProvider` (`lib/market-data/providers/angel-one.provider.ts`) implements only the REST `getLtpData` (LTP-only) and `getCandleData` endpoints — **no WebSocket client exists in this codebase, and no depth field is ever parsed.**
- **Bid/ask:** not separately confirmed as a REST field distinct from LTP in the endpoints AT24 currently calls; the `Full` WebSocket mode's depth response would supply top-of-book bid/ask as a byproduct of its 5-level depth payload (not verified against a live payload this sprint — no credentialed WebSocket call was made, per the sprint's explicit "no new integration" instruction).
- **Tick/streaming data:** confirmed to exist (`SmartWebSocketV2`, LTP/quote/depth modes) but **unused** by AT24.
- **Historical data:** confirmed limited to `getCandleData` (OHLC candles) — no evidence found of a historical tick or historical order-book product from Angel One at any tier.
- **Connection limits:** confirmed "up to three simultaneous WebSocket connections" per client/trading account.
- **Rate limits:** confirmed for order-related endpoints (10–20 requests/second for order placement/status, not directly relevant to read-only market data); a specific quote/LTP-endpoint rate limit was **not separately confirmed** this sprint.
- **April 1, 2026 policy change:** confirmed and read in full — this change (static-IP requirement, 10 orders/sec/exchange threshold, banned market/IOC orders for algo trading, mandatory broker-hosted execution for retail algos) is about **order execution/compliance under SEBI algo-trading rules**, and explicitly does **not** touch market data, quote/LTP/depth APIs, historical data, or data rate limits. **Not applicable to AT24's read-only market-data usage.**
- **Commercial/redistribution restrictions:** Angel One's general Terms of Use restrict redistribution of "research reports and analytical content" to the end user only; **no explicit clause specifically governing redistribution of raw market-data quotes/depth** was located this sprint — this should be treated as **NOT VERIFIED**, not as "permitted," before any redistribution-bearing feature is built.

## 9. Twelve Data / Alpha Vantage findings

Both are AT24's existing, already-integrated providers (Twelve Data primary, Alpha Vantage fallback with real EURUSD bid/ask since D2.8.1) — re-audited here specifically for microstructure capability, not general re-verification of D2.8.0/D2.8.1's already-confirmed findings.

- **Twelve Data:** confirmed quote/OHLC/time-series REST API; confirmed a WebSocket product exists for real-time price streaming ("up to 170ms latency," per its own documentation, quoted in a third-party summary), but **gated behind the Pro (individual) or Venture (business) paid tier** — AT24's current adapter is REST-only and does not use it. **No tick, Time & Sales, L2, or L3 product was found anywhere in Twelve Data's documentation at any tier.** Free tier confirmed at 800 calls/day, 8/min.
- **Alpha Vantage:** confirmed `CURRENCY_EXCHANGE_RATE` (what AT24 uses) is a polling REST endpoint with **no WebSocket product found**. Confirmed real bid/ask exists in this same endpoint's response (already exploited by D2.8.1). **No tick, Time & Sales, L2, or L3 product was found at any tier.** Free tier confirmed at 25 requests/day; premium real-time equity data (a different product from the FX/commodity endpoint AT24 uses) requires a $99.99+/mo tier and is explicitly gated by a "US market-data entitlement" separate from the API key itself, per Alpha Vantage's own pricing page.
- **Conclusion:** neither provider is, or will become, a source of AT24's missing microstructure capabilities at any subscription tier. Both remain exactly what D2.8.0/D2.8.1 already established them to be: real, honest, quote/OHLC-only sources.

## 11. Licensing/commercial-use considerations

- **dxFeed:** sales-gated, entitlement-managed, explicit redistribution-approval requirement. Least self-serve-friendly of the five; would require a real commercial negotiation before any production use, redistribution or otherwise.
- **Databento:** most self-serve-friendly — published usage-based pricing, a real (if credit-limited) free tier, explicit "licensed distributor" positioning suggesting cleaner redistribution rights than the others, though exact redistribution terms were **not separately verified** this sprint (would need a direct ToS read before committing).
- **Angel One SmartAPI:** free-with-account, but **not** a data-vendor relationship — it's a brokerage API. Its data-redistribution terms are the least clearly documented of the five (only "research reports" language was found, not a market-data-specific clause); this is a genuine, flagged gap, not a "safe to assume yes."
- **Twelve Data / Alpha Vantage:** both have clear, published, self-serve commercial tiers; Alpha Vantage's real-time *equity* product specifically calls out FINRA/SEC/exchange-regulatory entitlement requirements separate from the API key — a reminder that "premium key" and "real-time data rights" are not automatically the same purchase, a distinction that would matter if AT24 ever sought real-time equity data from Alpha Vantage (it currently does not — only FX/commodity).
