# D2.3 API Snapshot

Historical baseline of `app/api/private/*` at D2.3 freeze. Every route below is session-authenticated (`getUserOrNull()`, userId always session-derived, never trusted from the request body) and returns the standard `{status: "ok"|"error", data|error, meta}` envelope (`services/backend/ApiResponse.ts`), except market-data-facing routes which additionally carry the standardized failure DTO (`lib/market-data/error-dto.ts`) at `error.details`.

## Workspace & Market Data (D2.3)

| Route | Method | Purpose |
| --- | --- | --- |
| `/workspace/preferences` | GET/PATCH | Per-user workspace profile, symbol, favorites, panel state |
| `/market-data/snapshot` | GET | Single-symbol live snapshot (Workspace Header) |
| `/market-data/snapshots` | GET | Batch snapshots (Market Ribbon) |
| `/market-data/status` | GET | Primary/fallback provider + health summary |
| `/market-data/health` | GET | Full Provider Health Monitor detail |
| `/market-intelligence/analyze` | POST | Real evidence→reasoning→risk→confidence pipeline |
| `/trading-copilot/analyze` | POST | Live snapshot + indicators + AI restatement (also feeds the Intelligence Panel) |

## Publishing (D2.3.S1)

| Route | Method | Purpose |
| --- | --- | --- |
| `/publishing/articles` | GET/POST | List / create draft |
| `/publishing/articles/[id]` | GET/PATCH/DELETE | Read / edit / delete a single article |
| `/publishing/articles/[id]/publish` | POST | Publish (validated, then read-only) |
| `/publishing/articles/[id]/schedule` | POST | Schedule for future publish |
| `/publishing/articles/[id]/duplicate` | POST | Revise a published article via a new draft row |

## AI Assistant / Knowledge

| Route | Method | Purpose |
| --- | --- | --- |
| `/knowledge/chat` | POST | RAG chat, streaming (NDJSON) or blocking; always-on `AI_COMMUNICATION_POLICY` (D2.3.S4) |
| `/knowledge` | GET | List knowledge documents |
| `/knowledge/upload`, `/knowledge/ingest` | POST | Document ingestion pipeline |
| `/knowledge/search` | POST | Vector similarity search |
| `/knowledge/[knowledgeId]/reindex` | POST | Re-embed a document |
| `/conversations`, `/conversations/[conversationId]`, `/conversations/[conversationId]/messages` | GET/DELETE | Conversation lifecycle, lazy message hydration (D2.3.S2) |

## Removed in D2.3 (Final Audit)

`/api/ai` — an unauthenticated, policy-free direct Gemini proxy with zero live callers. Deleted, not deprecated; see `D2.3_KNOWN_LIMITATIONS.md` and the Final Audit section of the release notes.

## Unchanged in D2.3 (listed for completeness)

Admin (`/admin/*`), Billing (`/billing/*`, `/subscription`, `/plans`, `/products`), Agents (`/agents`), Automation (`/automations`, `/workflows`), Feedback (`/feedback`) — none of these were in D2.3's scope; see prior sprint documentation for their own baselines.
