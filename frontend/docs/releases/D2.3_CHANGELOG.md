## Net effect, by pillar

- **Workspace**: went from a set of separate pages to one coherent workspace with persisted per-user profiles/favorites and a shared design system.
- **Market Data**: went from a single-path provider call to a deterministic, honestly-labeled failover chain with real health monitoring.
- **AI Assistant**: cut the dominant latency source (unconditional search grounding) and eliminated an eager-fetch performance bug; gained real progress signals and a properly-honored Stop button.
- **Publishing**: went from a hardcoded mock array to a real, authorized, validated, per-user pipeline.
- **AI Compliance**: went from unwritten, inconsistent wording norms to one enforced, documented, machine-checkable policy applied at every AI entry point.

## Validation infrastructure added

23 deterministic (`no network`, injected-fake) validation scripts under `scripts/validate-*.ts`, plus one live-network compliance-verification script (`validate-ai-response-compliance.ts`) for manual review against the real Gemini API. All wired into `package.json`'s `validate:*` script family.
