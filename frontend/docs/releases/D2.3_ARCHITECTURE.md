# D2.3 Architecture Snapshot

Historical baseline of the platform's architecture as of D2.3 freeze. This is a snapshot, not a living document — see `docs/architecture/` and `docs/market-data-layer.md` for the current, maintained versions of the pieces still evolving in D2.4+.

## Layered structure

```
app/                    Next.js App Router - pages (app/dashboard/*) and API routes (app/api/private/*)
components/              Presentation only - no business logic, no direct fetch to a vendor
services/                Business logic, orchestration, one service per concern
lib/                     Provider-agnostic infrastructure (AI clients, market-data providers, shared utilities)
types/                   Shared TypeScript contracts between layers
prisma/                  Schema + hand-written migrations (see D2.3_DATABASE.md)
scripts/validate-*.ts    Deterministic, no-network validation suite (23 scripts as of freeze)
docs/                    Architecture references, this release-snapshot set, the AI style guide
```

## The five pillars

### 1. Workspace
`app/dashboard/workspace/page.tsx` + `components/workspace/*`. One page: symbol header (`WorkspaceHeader`), market ribbon, TradingView chart, AI Intelligence Panel, provider status indicator, workspace profiles (Scalper/Day Trader/Swing Trader/Investor), and favorite markets. State lives in `context/WorkspaceContext.tsx`; persisted profile/favorite state via `WorkspacePreference` (Prisma) and `app/api/private/workspace/preferences`.

### 2. Market Data Layer
`lib/market-data/` (providers, cache, reliability, error DTO, health monitor, registry) + `services/market-data/market-data.service.ts` (the single central service every consumer goes through) + `services/market-data/shared-instance.ts` (the one shared singleton every route imports). Twelve Data primary, Alpha Vantage secondary fallback. Deterministic failover: live → fallback provider → stale-but-recent cache (honestly labeled) → structured failure. Never fabricates a value.

### 3. AI / Intelligence Layer
`lib/ai/` (provider-agnostic AI client, the D2.3.S4 compliance policy modules: `response-policy.ts`, `terminology.ts`, `compliance.ts`, `disclaimer.ts`) + `services/ai/` (the deterministic evidence → reasoning → risk → confidence pipeline, the Trading Copilot / Intelligence Panel restatement layer, the AI Assistant's RAG chat orchestration, Publishing's draft-generation flow). The AI model is always a restate-only translator over already-computed structured data — it never performs independent analysis or invents a fact, per every prompt builder's own instructions.

### 4. Publishing
`services/publishing/article.service.ts` + `app/api/private/publishing/articles/**` + `components/publishing/*`. Real, per-user, DB-backed (`Article` model). Full lifecycle: draft → edit → schedule → publish → duplicate, with a persisted history log and per-user authorization scoping (`findOwned(userId, id)` on every access).

### 5. Backend Foundation
`services/backend/` (Middleware/`withContext`, `ApiResponse`, `Logger`, `ErrorHandler`, `RequestContext`). Every private route: session-derived `userId` only (never trusted from the request body), one consistent success/error envelope, structured logging, no raw error leakage to the client.

## Cross-cutting disciplines established this sprint series

- **Never fabricate**: every UI field is either a real computed value or an honest "Insufficient data"/"Not available" - enforced by the validate suite's own "no fabrication" structural tests (reasoning/risk/confidence/evidence engines).
- **One shared instance, not N disconnected ones**: `MarketDataService` is constructed once (`shared-instance.ts`) and injected everywhere, so cache and health-monitor state stay consistent across every route.
- **One AI communication policy, not five copies**: `AI_COMMUNICATION_POLICY` composed from `terminology.ts`/`compliance.ts`, imported at every prompt-building site.
- **One disclaimer, not per-surface strings**: `AI_DISCLAIMER_TEXT`, rendered via `components/ui/Disclaimer.tsx`.
- **Abort-safe fetches**: every workspace/assistant client fetch effect uses `AbortController` with cleanup; the AI Assistant's server-side stream now honors the request's abort signal too (Final Audit fix).

## Explicitly NOT in D2.3 scope (deferred to D2.4)

Market structure analysis (BOS/CHOCH), liquidity analysis, order blocks, fair value gaps, multi-timeframe intelligence, multi-agent reasoning, memory/learning systems. D2.3's AI layer is deterministic evidence-restatement; D2.4 is where genuine advanced financial intelligence begins.
